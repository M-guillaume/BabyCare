# Assets Directory

## alarm.mp3

Vous devez ajouter un fichier audio `alarm.mp3` dans ce dossier.

### Options pour obtenir un son d'alarme :

1. **Télécharger depuis Freesound.org**
   - Visitez : https://freesound.org
   - Recherchez "alarm" ou "siren"
   - Téléchargez un fichier gratuit (licence Creative Commons)

2. **Utiliser un site de sons libres**
   - https://mixkit.co/free-sound-effects/alarm/
   - https://pixabay.com/sound-effects/search/alarm/

3. **Créer votre propre son**
   - Utilisez Audacity (gratuit) pour enregistrer ou générer un son
   - Exportez en format MP3

### Spécifications recommandées :
- Format : MP3
- Durée : 3-5 secondes (sera joué en boucle)
- Qualité : 128-192 kbps
- Volume : Normalisé à -3dB

### Note :
Sans ce fichier, l'application utilisera seulement la vibration comme alarme.
