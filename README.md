# BabyCare — 2026 IEEE AP-S Student Design Contest

Open-source repository of the **BabyCare Team** for the **2026 IEEE AP-S Student Design Contest** hosted by the [IEEE AP-S / URSI 2026 Symposium](https://2026.apsursi.org/sdc.php).

## **Project**
**Child Deaths in Hot Cars Preventing System**

A smart embedded system designed to help prevent child deaths caused by heat exposure inside parked vehicles.

## **Team**
Developed at **ENSEIRB-MATMECA Engineering School, France**
